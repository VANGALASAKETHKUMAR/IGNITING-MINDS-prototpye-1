# Igniting Minds Aerospace — Requirements Tracker

Use this with the CSV for Excel/Google Sheets. Update **Owner**, **Due Date**, **Status**, and **Received Date** as assets arrive.

**Status values:** `Not started` · `Requested` · `In progress` · `Received` · `Approved` · `Blocked` · `N/A`

**How to use**
1. Open `igniting-minds-requirements-tracker.csv` in Excel or Google Sheets.
2. Fill Owner / Due Date for each row.
3. Change Status when files are shared (Drive/Dropbox/email).
4. Put the file link in Notes / Link.

## Priority legend
- **Must have** — needed for a credible production launch
- **Should have** — strong polish; schedule soon after launch pack
- **Nice to have** — enhances experience; optional for v1
